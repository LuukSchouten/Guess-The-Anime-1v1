Put your own sound files in this folder. Use these exact names:

  correct.mp3   - a player answers correctly
  wrong.mp3     - a player answers wrong
  reveal.mp3    - nobody got it, the answer is shown
  win.mp3       - a player wins the game
  draw.mp3      - the game ends in a draw

.mp3, .wav and .ogg all work (e.g. correct.wav). If a file is missing, that event is silent.
After adding files, refresh the game page (Ctrl+F5).
